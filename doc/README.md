# Documentation

Greater NY Live Transit is a live map of the regional trains and buses that carry commuters into and
out of Manhattan: LIRR, Metro-North, NJ Transit rail and NJ Transit bus, with PATH and ferries planned.
NYC Subway and NJ light rail are deliberately out of scope. It's a non-commercial hobby project that
must run at $0.
